> **AWS 프리티어 $200으로 EKS 실습하기 ①** · 💰 이 편은 읽기만 하면 됩니다. 비용 **$0**

쿠버네티스를 배우려고 검색하면 나오는 글은 대개 두 종류입니다. 노트북에 minikube를 깔아 보는 글과 회사에서 이미 돌고 있는 클러스터를 전제하는 글인데, 앞쪽은 실제 클라우드가 아니라서 네트워크도 스토리지도 흉내만 내고 뒤쪽은 클러스터를 만들어 보는 경험 자체를 건너뜁니다.


그 사이가 비어 있습니다. 직접 세워 보고는 싶은데 AWS는 켜는 순간부터 돈이 나가고, 얼마가 나갈지 모르는 상태에서는 `apply`를 누를 용기가 좀처럼 생기지 않습니다.


이 시리즈는 그 빈칸을 신규 계정 크레딧 $200으로 메웁니다. 열두 편을 따라가면 VPC부터 HTTPS 인증서까지 전부 직접 세운 클러스터가 손에 남는데, 거기 실제로 들어가는 돈은 $3 안쪽입니다. 저는 두 달 걸려 **$2.94**를 썼습니다.


이번 편에는 코드가 없습니다. 무엇을 만들 것인지와 돈이 정확히 어디서 나가는지를 먼저 보는데, 이 두 가지를 모르고 덤비면 아예 시작을 못 하거나 시작하고 나서 겁이 나 중간에 멈추기 때문입니다.

> 이 글의 다이어그램 중 공식 문서에서 인용한 것을 제외한 나머지는 AI 가 코드로 작도했습니다. 수치는 실제 청구·실행 기록이지만 배치나 표기에 오류가 있을 수 있으니, 그림보다 본문의 표를 기준으로 읽어주시기 바랍니다.
> 쿠버네티스를 클라우드에서 배우는데 돈을 얼마나 써야 하는가?

## 📘 EKS는 쿠버네티스를 대신 운영해 주는 서비스입니다


용어부터 정리합니다. 아는 분은 건너뛰어도 됩니다.


**쿠버네티스(Kubernetes)는 컨테이너를 여러 서버에 나눠 돌려 주는 프로그램**입니다. 컨테이너를 직접 서버에 올리면 어느 서버에 몇 개를 띄울지, 죽으면 누가 다시 띄울지를 사람이 전부 정해 줘야 하는데, 쿠버네티스에는 _"이 앱을 2개 띄워 둬"_ 라고 선언만 하면 그 상태를 알아서 유지합니다.


이 프로그램은 두 부분으로 되어 있습니다.


| 부분         | 하는 일                 | 비유  |
| ---------- | -------------------- | --- |
| **컨트롤플레인** | 명령을 받고 상태를 결정합니다     | 관제탑 |
| **노드**     | 실제로 컨테이너가 돌아가는 서버입니다 | 활주로 |


```plain text
kubectl ──►  ┌───────────────────────────────┐
             │  컨트롤플레인                   │   관제탑
             │  API 서버 · 스케줄러 · etcd     │   EKS 에서는 AWS 가 운영합니다
             └───────────────┬───────────────┘
                             │  "이 상태를 유지해라"
             ┌───────────────▼───────────────┐
             │  노드                          │   활주로
             │  [ 앱 Pod ]     [ DB Pod ]     │   내가 고르고 내가 냅니다
             └───────────────────────────────┘
```


직접 설치하면 관제탑도 내 손으로 세워야 합니다. 서버 세 대에 etcd를 띄우고 인증서를 발급하고 버전 업그레이드까지 직접 해야 하는 일이라, 쿠버네티스를 배우려던 사람이 쿠버네티스 설치를 배우다 지칩니다.


**EKS(Elastic Kubernetes Service)는 그 관제탑을 AWS가 대신 운영해 주는 서비스입니다.** 노드는 내가 고르고 컨트롤플레인은 AWS가 맡는데, 배우는 입장에서는 쿠버네티스를 쓰는 법에 집중할 수 있고 대신 관제탑 사용료를 냅니다.

> **📘 ECS와 뭐가 다른가요**
> 
> AWS에는 ECS라는 비슷한 서비스가 있고 더 싸고 쉽습니다. 다만 **ECS는 쿠버네티스가 아닙니다.** AWS가 따로 만든 것이라 `kubectl`도 Pod도 매니페스트도 없고, 개념이 대응되는 물건은 있지만 쿠버네티스를 배우려는 목적이라면 옮겨 쓸 수 있는 게 거의 없습니다. 이 시리즈가 더 비싸고 더 느린 EKS를 쓰는 이유입니다.

## 🔴 돈은 세 군데서 나갑니다


여기가 이번 편의 핵심입니다. EKS가 무섭게 느껴지는 이유는 요금표가 복잡해서가 아닙니다. 뭘 켜면 돈이 나가는지 모르는 상태라서입니다. 지도를 먼저 그립니다. 서울 리전 기준입니다.


| 무엇                       | 시간당       | 한 달 켜 두면 | 끌 수 있나                 |
| ------------------------ | --------- | -------- | ---------------------- |
| **EKS 컨트롤플레인**           | **$0.10** | **$73**  | 🔴 클러스터를 **지워야만** 멈춥니다 |
| ALB (로드밸런서) 세트           | $0.0405   | $29.6    | Ingress를 지우면 멈춥니다      |
| EC2 노드 `t4g.small` 1대    | $0.0208   | $15.2    | 대수를 0으로 줄이면 멈춥니다       |
| 노드 퍼블릭 IP 1개             | $0.005    | $3.65    | 노드와 함께                 |
| EBS 볼륨 10GB              |           | $0.91    | 🔴 **클러스터를 지워도 남습니다**  |
| S3, DynamoDB, IAM, 예산 알림 |           | ~$0      | 계속 켜 둬도 됩니다            |


표에서 세 가지만 기억하면 됩니다.


**가장 비싼 것은 컨트롤플레인입니다.** 노드를 한 대도 띄우지 않아도 시간당 $0.10이 꼬박꼬박 나가고, 한 달을 켜 두면 $73이라 크레딧 $200의 3분의 1이 여기서 사라집니다.


**노드를 줄이는 것으로는 막을 수 없습니다.** 클라우드 비용을 아끼는 기본 수단이 인스턴스를 줄이는 것인데, 노드를 전부 0으로 내려도 컨트롤플레인과 로드밸런서는 그대로 돌아서 월 $102가 계속 나가기 때문에 여기서는 그 수단이 통하지 않습니다. 전체의 **60%가 노드와 무관한 고정비**입니다.


**볼륨은 클러스터보다 오래 삽니다.** 데이터를 담아 두는 EBS 볼륨은 일부러 클러스터 밖에 두기 때문에 클러스터를 지워도 월 $0.91이 계속 나가는데, 금액은 작아도 _"다 지웠는데 왜 돈이 나가지"_ 의 범인이 보통 이것입니다.

## 그래서 규율은 하나입니다. 쓸 때만 켭니다


고정비가 60%라는 말을 뒤집으면 꺼져 있는 동안은 진짜로 $0이라는 뜻입니다. 이 시리즈가 처음부터 이렇게 가는 이유입니다.

> 실습을 시작할 때 `tofu apply`로 클러스터를 만들고, 끝나면 `tofu destroy`로 지웁니다. 클러스터는 실습과 실습 사이에 **존재하지 않습니다.**

처음에는 번거롭게 들립니다. 클러스터를 만드는 데 10분쯤 걸리니 매번 10분을 버리는 셈인데, 비용을 계산해 보면 생각이 바뀝니다.


```plain text
클러스터를 처음부터 다시 만들기   약 $0.07
4시간 실습 한 번                 약 $0.64
하루 종일(8시간) 삽질             약 $1.28
```


**망쳐도 7센트입니다.** `apply`가 깨져서 전부 지우고 다시 세워도 커피 한 잔의 100분의 1이라, 이 시리즈에서는 마음껏 부수시면 됩니다. 아껴야 하는 것은 크레딧이 아니라 켜 놓고 딴짓하는 시간입니다.

> **📘 Terraform이 아니라 OpenTofu를 씁니다**
> 
> 이 시리즈는 콘솔 클릭 없이 전부 코드로 만들고, 그 도구가 Terraform에서 갈라져 나온 오픈소스 버전인 OpenTofu입니다. 명령어와 문법이 거의 같아서 `tofu`를 `terraform`으로 바꿔 읽어도 대부분 동작합니다. **코드로 만드는 이유는 자동화가 아니라 반복과 삭제입니다.** 켜고 끄기를 수십 번 할 참인데 콘솔 클릭으로는 그걸 못 합니다.

## $200로 실제로 얼마나 할 수 있나


저는 두 달 동안 이 과정을 돌면서 **$2.94**를 썼습니다. 크레딧의 **1.5%**입니다.


|           |                                      |
| --------- | ------------------------------------ |
| 크레딧       | $200 (신규 계정, 6개월 만료)                 |
| 실제 지출     | **$2.94**                            |
| 한 번 실습    | 20~30분, $0.05~0.21                   |
| 가장 비쌌던 하루 | $2.77 (실수로 15.8시간 켜 뒀습니다. ⑫편에서 다룹니다) |


크레딧이 모자랄 걱정은 하지 않아도 됩니다. 이 시리즈를 두 번 완주해도 $10을 안 넘는데, 그건 끄는 걸 잊지 않았을 때의 숫자이고 잊으면 하루에 $2.4씩 나갑니다. ③편에서 알림을 걸고 ⑫편에서 자동으로 끄는 장치를 만듭니다.

②편에서 손을 쓰기 시작합니다. 미리 준비하면 좋은 것들입니다.


| 필요한 것  | 비고                                                |
| ------ | ------------------------------------------------- |
| AWS 계정 | **새로 만드세요.** 기존 계정은 크레딧 대상이 아닙니다                  |
| 신용카드   | 계정 생성에 필요합니다. 크레딧 안에서 쓰면 청구는 없습니다                 |

⚠️ **계정을 만들 때 밟으면 크레딧이 그 자리에서 사라지는 함정이 하나 있습니다.** SSO를 켜려다 조직을 만들면 무료 플랜에서 이탈하는데, 계정을 미리 만드실 거면 **조직(Organizations)과 IAM Identity Center는 건드리지 마세요.** ②편의 첫 번째 경고가 이것입니다.

## 어디서 비싸지는가


이 시리즈가 모든 것을 가르쳐 주지는 않습니다. 시작 전에 알아 두시면 좋은 한계입니다.


**프로덕션 구성이 아닙니다.** 노드를 가용 영역 한 곳에 몰아 두고 NAT 게이트웨이를 쓰지 않고 데이터베이스를 클러스터 안에 두는데, 전부 비용을 줄이기 위한 선택이라 실제 서비스라면 다르게 해야 합니다. 각 편에 _"실제 운영이라면 이렇게 안 합니다"_ 를 따로 적어 두겠습니다.


**상시 켜 두는 구성은 다루지 않습니다.** 이 시리즈의 전제가 쓸 때만 켜는 것입니다. 24시간 돌리면 월 $170이고 크레딧은 5~6주에 사라집니다. 그 계산은 ⑫편에 있습니다.


**AWS 콘솔 사용법은 거의 안 나옵니다.** 전부 코드와 명령어로 합니다. 화면 캡처가 한 장도 없는 이유는 AWS 콘솔 화면이 자주 바뀌어서 캡처가 코드보다 빨리 낡기 때문인데, 클릭으로 하는 법을 찾으시는 분께는 맞지 않습니다.


**쿠버네티스 입문서는 아닙니다.** Pod나 Deployment 같은 개념은 처음 나올 때 설명하지만 체계적으로 배우는 목적이라면 공식 문서를 함께 보시는 편이 좋습니다.

## 정리


| 알아 둘 것     | 내용                                               |
| ---------- | ------------------------------------------------ |
| EKS가 뭔가    | 쿠버네티스의 관제탑을 AWS가 대신 운영해 주는 서비스입니다                |
| 돈이 어디서 나가나 | 컨트롤플레인 시간당 $0.10이 가장 크고, 전체의 60%가 노드와 무관한 고정비입니다 |
| 왜 매번 지우나   | 꺼 두면 진짜로 $0이고, 다시 만드는 비용이 $0.07이라 망쳐도 괜찮습니다      |
| 얼마 드나      | 두 달 완주에 $2.94. 끄는 걸 잊지 않는다면 크레딧은 남습니다            |
| 뭘 조심하나     | 계정 만들 때 조직을 만들면 **크레딧이 즉시 만료**됩니다                |


처음 질문으로 돌아가면, 쿠버네티스를 클라우드에서 배우는 데 드는 돈은 $3 정도입니다. 생각보다 적은데 요금이 싸서가 아닙니다. 켜 두는 시간을 짧게 만들 수 있기 때문입니다.

> 클라우드 비용은 무엇을 켜느냐보다 **얼마나 오래 켜 두느냐**가 정합니다.

②편에서 도구를 설치하고 AWS 계정을 준비합니다. 여기서도 돈은 나가지 않습니다.
